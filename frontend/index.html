DONNÉES DE L'APPLICATION

Import & migration

Prévisualisez les fichiers Excel de référence dans data/ ou importez un nouveau fichier.

SOURCE DE DONNÉES

Base SQLite locale

Les nouvelles saisies et imports validés sont enregistrés dans la base SQLite du serveur. Les classeurs Excel restent disponibles comme sources et ne sont jamais modifiés par l'application.

Pour migrer un stock et son historique, importez d'abord le stock, puis les commandes, les entrées et enfin les sorties. Les lignes historiques de mouvements n'ajustent pas les quantités du stock, sauf si vous cochez l'option correspondante.

SURVEILLANCE AUTOMATISÉE

Veille & alertes

Les seuils de stock et dates d'expiration sont vérifiés à chaque actualisation.

IMPORT DE COMMANDES

Ajouter depuis un fichier

Choisissez un fichier CSV ou Excel avec les colonnes Produit, Quantité et Fournisseur. La date de livraison prévue est facultative. Les doublons seront ignorés.

IMPORT CONTRÔLÉ

Préparer un import

Choisissez le type de données. Vous pouvez utiliser un classeur de référence présent dans data/ ou téléverser un fichier CSV/Excel. L'aperçu signale les erreurs et doublons ; aucune écriture n'a lieu avant confirmation.

GestionAgent

Votre interlocuteur pour les questions et opérations de gestion. Ses réponses utilisent les données SQLite, les documents SharePoint configurés et les outils Foundry. Toute proposition attend votre confirmation avant l'écriture.
