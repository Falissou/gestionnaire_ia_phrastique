DONNÉES DE L'APPLICATION

Import & migration

Prévisualisez les fichiers Excel de référence dans data/ ou importez un nouveau fichier.

SOURCE DE DONNÉES

Base SQLite locale

Les nouvelles saisies et imports validés sont enregistrés dans la base SQLite du serveur. Les classeurs Excel restent disponibles comme sources et ne sont jamais modifiés par l'application.

Pour migrer un stock et son historique, importez d'abord le stock, puis les commandes, les entrées et enfin les sorties. Les lignes historiques de mouvements n'ajustent pas les quantités du stock, sauf si vous cochez l'option correspondante.

SURVEILLANCE AUTOMATISÉE

Veille & alertes

Les seuils de stock et dates d'expiration sont vérifiés à chaque actualisation.

VALIDATION FOURNISSEUR

Vérifier le bon de commande

Vérifiez le fournisseur, les quantités et les prix. La validation enregistrera la commande comme passée et téléchargera le bon au format Excel.

IMPORT CONTRÔLÉ

Préparer un import

Choisissez le type de données. Vous pouvez utiliser un classeur de référence présent dans data/ ou téléverser un fichier CSV/Excel. L'aperçu signale les erreurs et doublons ; aucune écriture n'a lieu avant confirmation. Pour réceptionner un bon de commande, choisissez l'onglet « Import entrée », renseignez la date réelle de réception dans « Date Entrée », sélectionnez « Entrées de stock » et cochez l'ajustement du stock.
